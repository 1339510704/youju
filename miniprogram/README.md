## 一、现在需要你做的只有 3 件事

> 其余的都已在工程里准备好（数据库会自动创建）。

### 第 1 步 · 让模拟器正常显示

如果右侧手机框还在显示 **「模拟器启动失败」**：

- 这是开发者工具**第一次**打开项目时，正在后台下载基础库（约 40 MB，日志显示花了 29 秒）造成的——下载没完成，模拟器就启动超时。
- **解决办法：再点一次工具栏上的「编译」按钮**（快捷键 `Ctrl + B`）。基础库已经下载完了，这次通常就正常了。
- 如果还是失败，按顺序试：
  1. 点「编译」旁边的下拉箭头 → **清缓存 → 全部清除**，然后重新编译；
  2. 菜单 `工具 → 设置 → 通用设置` → 关掉 **「使用硬件加速」**，重启开发者工具；
  3. 关掉开发者工具再重新打开项目。

### 第 2 步 · 开通云开发（数据存这里）

1. 点开发者工具**顶部工具栏的「云开发」**按钮；
2. 弹窗里点**开通**，选**免费基础版**，随便起个环境名（例如 `home-space`）→ 确定；
3. 开通后左上角会显示**环境 ID**，形如 `home-space-1g2h3i4j5k6l7m`，**复制它**；
4. 打开项目根目录的 `config.js`，把 `CLOUD_ENV` 的值换成这个环境 ID，**保存**。

> 想省事：把环境 ID 发我，我直接帮你写进 `config.js`（云函数部署见第二节）。

### 第 3 步 · 部署 5 个云函数

在开发者工具左侧的资源管理器里展开 **`cloudfunctions`**，里面有 5 个文件夹：


## 三、发布上线（上传前端代码）

「编译 / 上传前端 / 上传云函数」三者关系不同，发布时各自独立：

- **编译**：开发者工具在本地把代码跑起来（模拟器 / 真机预览），仅用于自测，**不是发布必需**。用命令行上传时工具内部已包含编译。
- **上传（前端）**：把前端代码包传到微信后台，生成「开发版本」——这是**提交审核的唯一前提**。
- **云函数上传**：见第二节，只改了哪个云函数才需要单独传；前端上传不会带上云函数。

**用 `miniprogram-ci` 上传前端**（装在**全局**，不要装进项目根目录 —— 原因见下方警告）：

```bash
npm i -g miniprogram-ci

miniprogram-ci upload \
  --appid wxa355fe96a761e38a \
  --private-key-path "private.wxa355fe96a761e38a.key" \
  --project-path "." \
  --version 1.0.3 \
  --desc "家庭协作：点菜接单、公开菜单、小红花激励、每日签到" \
  --type miniProgram
```

> 版本号每次上传必须比微信后台已有的开发版本号大，按需递增。
>
> 上传私钥 `private.wxa355fe96a761e38a.key` 已在 `.gitignore` 排除、并在 `project.config.json` 的 `packOptions.ignore` 排除出代码包，**切勿提交或外传**。
>
> 上传生成「开发版本」后，去 `mp.weixin.qq.com → 管理 → 版本管理` 提交审核即可。

> ⚠️ **永远不要在小程序项目根目录执行 `npm install`**。曾经为了装上传工具在根目录留下 `node_modules` / `package.json`，导致开发者工具转译时找不到辅助模块、整个页面 JS 加载失败（白屏 + 旧界面阴魂不散）。现在这两者已加进 `packOptions.ignore`，上传工具请一律全局安装。

## 六、定时提醒要到点弹微信通知，还差一步

微信规定：**发服务通知必须用你自己申请的消息模板**，模板 ID 不能借用别人的。

1. 打开 `mp.weixin.qq.com`（小程序管理后台）→ `功能` → `订阅消息` → `公共模板库`，挑一个「日程提醒 / 待办提醒」类的模板，点「选用」；
2. 拿到**模板 ID**（形如 `Xk3j...`）；
3. 填进 `config.js` 的 `REMINDER_TEMPLATE_ID`；
4. 重新上传部署 `remind` 云函数。

**不填也能用**：提醒会照常保存、在 App 内的列表里显示到期状态，只是不弹微信通知。

两个额外说明：

- 微信的订阅消息是**一次性授权**——用户授权一次只能收到一条推送。App 里每次保存提醒时都会顺手请求一次授权，攒授权次数。
- `remind/config.json` 里配的是「每分钟触发一次」的定时触发器。用**右键「上传并部署」**时触发器会一起创建；如果你是用命令行部署的，需要去云开发控制台的「云函数 → remind → 触发器」里确认一下。

## 八、常见问题

**Q：首页一直显示「云函数还没部署」**
A：`cloudfunctions` 下 5 个文件夹（space / content / flower / remind / init）要**逐个**右键上传部署，不是只部署一个。

**Q：提示「云开发环境 ID 不对」**
A：`config.js` 里的 `CLOUD_ENV` 必须是云开发面板里那一串**环境 ID**（形如 `xxx-1a2b3c`），不是环境名称，也不能带空格。

**Q：「一键初始化数据库」按钮在哪儿？我没找到**
A：这个按钮**不是常驻的**，它是一张「出问题才出现」的兜底卡片 —— 只有「云函数通了但数据库集合没建好」时，才会在**首页**顶部弹出来。看不到它，通常说明**数据库早就自动建好了**，是正常现象。

想随时手动检查/重建，走这条固定路径：**「我的」页 → 拉到最下面「系统状态」卡片 → 「检查 / 一键初始化数据库」**。这个入口永远在，三盏灯（云开发 / 云函数 / 数据库）一眼就能看出哪里没通。

**Q：提示「数据库集合还没建好」且自动创建失败**
A：确认 `init` 云函数也部署了，然后去「我的」→「系统状态」→ 点「检查 / 一键初始化数据库」。实在不行，去云开发控制台 → 数据库 → 手动新建这些集合：`spaces`、`members`、`users`、`flowerLogs`、`codes`、`dishes`、`orders`、`todos`、`festivals`、`reminders`、`finance`、`plans`、`rewards`、`rewardOrders`（共 14 个；App 启动时会自动补建缺失的，一般不用手工建）。

**Q：会员兑换码怎么生成？**
A：两条路。① 用户自己攒小红花，在「我的 → 小红花与会员 → 用小红花兑换」里自助开通；② 你在云开发控制台 → 数据库 → `codes` 集合里新增一条记录：`{ "code": "HSMP-2026-0001", "level": 1, "days": 30 }`，把 code 发给用户，用户在「会员中心 → 兑换码」里激活。一个码只能用一次。`level` 1=小红花会员、2=超级会员。

**Q：每日签到在哪？能领几次？**
A：点首页顶部那个「家 ♥」（房子图标 + 大字）即可签到，**+2 朵小红花**，**每个账号每天只能领 1 次**——由 `flower` 云函数的 `checkin` 动作按 openid **全局**判定，换空间也领不到第二次。签到成功不弹窗、不加文案，只体现为右上角花朵数 +2；当天已签过再点则静默无反应。该规则写在 `EARN_RULES.checkin`（`delta: 2, daily: 1`）。

**Q：赚到小红花的提示写在哪？想改文案**
A：统一在 `utils/flower.js` 的 `toastEarn(n)`——只有**真正发到花**时才弹「获得 N 朵小红花」（撞每日上限 / 重复操作发到 0 朵就安静跳过）。数字来源是云端：`content` 云函数在 `add / toggle / takeOrder / finishOrder / addComment` 的响应里回传 `earned` 字段，前端拿到才提示。所以**改完云函数必须重新部署**，否则前端收不到 `earned`、不会弹。

**Q：编译报错 `module '@swc/runtime/_sliced_to_array.js' is not defined` / 页面白屏**
A：开发者工具把 ES6 **数组解构**（`const [a, b] = await Promise.all([...])`）转 ES5 时要注入 `@swc/runtime` 辅助模块，找不到就整个页面的 JS 加载失败——表现是「怎么清缓存、重新上传都还是旧界面」。本项目已做两层处理：
1. `project.config.json` 里 `"es6": false`、`"enhance": false`（基础库 3.x 原生支持 ES6，根本不需要转译）；
2. 全部 7 处数组解构已改成下标取值（`const _pa = await Promise.all(...); const a = _pa[0];`）。

**新增代码请不要再写数组解构**，也不要在项目根目录 `npm install`。

**Q：小红花能不能被刷？**
A：做了三层防护：每人每天每类行为有次数上限；同一道菜同一规则只算一次；户主可以手动加减花纠偏。规则表在 `cloudfunctions/flower/index.js` 顶部的 `EARN_RULES`，想调数值直接改那一个地方。

**Q：想让家人加入**
A：在「我的」页复制那个空间的**邀请码**（6 位），发给对方；对方打开小程序 → 「我的」→「邀请码加入」→ 填入即可。同一个家庭里的点单、待办、理财都是共享的。
