# 有据 · 证据消费层

> 元宝能帮你搜到答案，但没告诉你**哪些证据配进答案**。
>
> 搜索层（元宝 / 麦当劳 MCP）已经把召回、清洗、权威打分做完了。它给你一列结果，
> 但不负责裁决：哪条能进答案、冲突时谁说了算、排除了为什么。
> 我们补的就是这一层，并把它做成三个能直接打开用的产品，再装进微信。

在线体验：**https://youju.robai.dpdns.org/**

## 三个产品

### 1. AI 侦探社 · 事实核查与证据链

**功能**：输入一个问题，调用元宝搜索全网召回，按来源分级后给出答案。答案的每一句都来自原文，可点击定位到具体片段，并标注结论由几条独立信源印证。查不到就直说查不到。

**完成度**：查证 / 盯梢模式 / 来源战绩三个页面全部上线；接真实元宝搜索接口；支持公开提问，可看到其他人在问什么。✅ 可完整使用

**价值**：把「读十篇网页判断真假」压缩成「扫一眼高亮」。写材料、对外发言被追问依据时，能立刻点开原文，而不是回答「AI 说的」。

- 在线：https://zhentanshe.robai.dpdns.org/
- 盯梢模式：https://zhentanshe.robai.dpdns.org/watch
- 来源战绩：https://zhentanshe.robai.dpdns.org/sources

### 2. 真假鉴定所 · 判断力训练

**功能**：写一句想验证的说法，系统真实检索召回证据，并按来源可信度分级（官方 / 学术 / 主流 / 垂直 / 自媒体 / 营销）。你自己判断真、假或说不准，答错不扣分，选「说不准」是正确操作。

**完成度**：已用真实检索取代预设题库；来源分级按真实域名判定；证据可点开原文；可高亮关键句；黑白双主题。✅ 可完整使用

**价值**：家族群转来的「某食物致癌」，不用信也不用吵，30 秒看到真实信源分布。同时训练「先看来源再下判断」的习惯。

- 在线：https://zhenjiajiandingsuo.robai.dpdns.org/

### 3. 今日三件 · 生活规划

**功能**：说你最近在考虑什么——备孕、考研、结婚、换工作。系统按你的情况检索公开信息，排出该做的事，每件都写清**为什么现在做**、**具体怎么做**、**依据在哪**。

**完成度**：输入、分阶段清单、引用依据的完整交互已完成；四类场景结构已定形；检索与自动生成尚未接入（当前为标注清楚的示例数据）。⚠️ 界面完成 · 检索接入中

**价值**：面对人生节点的人，知道目标但不知道第一步做什么，网上信息互相矛盾还被营销号包围。这里把「该做的事」按阶段排出来，并标明依据。

- 在线：https://jinrisanjian.robai.dpdns.org/

## 为什么装进微信小程序

一条传言是从群里转来的。让人「复制 → 打开浏览器 → 贴进另一个网站」，这一步流失掉了 99% 的人。
所以三个产品都要进小程序：**在哪个群看到，就在哪儿查**。

| 产品 | Web 端 | 小程序 |
|---|---|---|
| AI 侦探社 | 已上线 | 接入中 |
| 真假鉴定所 | 已上线 | 接入中 |
| 今日三件 | 界面完成 | 待接入 |

**技术要点**：小程序不能直接请求业务域名（`dpdns.org` 未备案，微信 request 白名单过不了），
因此统一由**微信云函数中转** —— 密钥留在服务端，不进小程序包；以后换引擎也不用重新发版。

## 技术栈

| 层 | 用什么 |
|---|---|
| 检索 | 腾讯云元宝搜索 MCP（SearchPro） |
| 判断 | Bocha Jev（`bocha-jev-v1`，score / noul 题型） |
| Web 部署 | Cloudflare Workers + 自定义域名 |
| 小程序 | 微信云开发（云函数 + 云数据库 + 云存储） |

**不做生成，做抽取**：答案的每一句都是原文子串，不转述、不改写。这是从结构上防归因错误 ——
AI 说错话最难查的，就是它把三篇不同来源揉成了一句。

## 本地运行

### Web 端

每个产品目录是一个独立的 Worker：

```bash
cd web/zhentanshe
npm install
# 配置环境变量（不要写进代码）：
#   CLOUDFLARE_API_TOKEN / CLOUDFLARE_ACCOUNT_ID
#   WSA_API_KEY       元宝搜索密钥
#   BOCHA_JEV_API_KEY Jev 判断密钥
npx wrangler dev      # 本地预览
npx wrangler deploy   # 部署
```

### 小程序

用微信开发者工具打开 `miniprogram/` 目录。

**首次运行需要自己建一个 `cloudfunctions/pay/config.js`**：

```bash
cp cloudfunctions/pay/config.example.js cloudfunctions/pay/config.js
# 然后填入你自己的 AppKey / AppSecret
```

该文件已被 `.gitignore` 排除，不会提交到仓库。

## 我们不做什么

- **不判断材料本身真假**。只能标记、分级、交叉印证。原材料是假的，我们也救不回来 —— 这是行业共同边界。
- **不替代人工复核**。只是把「读十篇网页」压缩成「扫一眼高亮」。
- **不做自主多轮调研**。现在是并行多路召回，不是「搜→读→改问法→再搜」的自主循环。
- **GEO 只能拦一部分**。同源马甲、伪权威站、AI 内容农场还需要 IP、备案、模板指纹等外部数据。
- **不声称「AI 不会说错」**。只声称「说错了你能查到」。
